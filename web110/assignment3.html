For Activity 1, I used search engines and operators. Using operators made the search results more focused and useful. Searching “search engine” and “market share” with quotation marks gave more precise results than searching without quotes because it looked for the exact phrases instead of pages containing the words separately. Using site:wikiversity.org was helpful because it limited the results to wikiversity and quickly found relevant information, although wikiversity’s own special search can be used for finding newer or less indexed pages. The Boolean search “ search engine” or SEO broadened the results by including information about either search engines or SEO. For Activity 2, I learned about Search Engine Optimization, or SEO. To learn about Search Engine Optimization (SEO), I looked at Google's guidance on getting content indexed. SEO helps search engines understand webpages and can improve their visibility in search results. To practice submitting a webpage, you can use Google Search Console's URL inspection tool to request indexing of a specific page. To do so, copy the URL of the Wikiversity page for example, and paste it into the URL inspection tool and select request indexing.
