Assignment 10: CSS Cascade and Specificity

In this assignment, I learned how CSS specificity and the cascade rule work when applying external, internal, and inline styles. Understanding how inline styles override internal and external definitions helps me control element presentation dynamically. In future web development projects, I can use external style sheets to maintain a consistent site-wide layout while using internal or inline styles intentionally for unique component design and temporary visual overrides.
