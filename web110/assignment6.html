For Activity 1, I focused on Internet Services and Internet Collaboration. I learned that the Internet provides many different services, including email, instant messaging, file transfer, video conferencing, and access to information through the World Wide Web. I also learned that Internet collaboration allows people to communicate and work together even when they are in different locations. I selected Google Chat as the communication application because it provides real-time messaging and group communication. This activity helped me understand how communication tools can be used in both personal and professional situations. I can apply this knowledge by using online messaging and collaboration tools to communicate with classmates, coworkers, friends, and family without being in the same physical location. These tools could also help me participate in group projects, exchange information quickly, and stay organized when working with others. For Activity 2, I used screen sharing and Remote Desktop applications. I learned that remote-desktop programs such as Chrome Remote Desktop allow an authorized user to access another computer from a different device. This can be useful for viewing files, accessing programs, troubleshooting computer problems, or providing technical support. An important lesson from this activity was that remote access should occur only with the computer owner's permission and proper authentication. I can apply this knowledge personally by using remote-desktop technology when I need to access my own computer from another location or help someone troubleshoot a computer problem. Understanding remote access also gives me a better awareness of computer security because unauthorized remote access could create significant privacy and security risks. For Activity 3, I covered FTP and Intellectual Property. I learned that FTP, or File Transfer Protocol, is used to transfer files between a client and a server. I also learned that traditional FTP does not encrypt information, so secure alternatives should be considered when transferring sensitive information. The intellectual property portion taught me that copyrighted material cannot generally be copied or distributed without authorization. Peer-to-peer technology has legitimate uses, but unauthorized sharing of copyrighted music, movies, software, or other works can result in legal consequences. I can apply this knowledge by choosing legitimate sources when downloading or sharing digital content and by being more careful about the security of files I transfer online. Overall, these activities increased my understanding of how Internet technologies work and how they can be used responsibly, securely, and legally.
